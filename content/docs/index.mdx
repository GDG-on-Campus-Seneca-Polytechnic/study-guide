This is the study guide for GDG on Campus @ Seneca Polytechnic. It has three parts.

| Part | What it is | Start with |
|---|---|---|
| [Get set up](/docs/setup) | Sign-up guides for free student tools. Each is a short list of steps with screenshots. | [Get a Gemini API key](/docs/setup/ai-studio-key) |
| Tracks: [Web](/docs/web), [Cloud](/docs/cloud), [AI and ML](/docs/ai), [Mobile](/docs/mobile) | An overview and one or two starter lessons per track. Each lesson builds one small thing. | The track you are most curious about |
| [Code Jam](/docs/code-jam) | What to do on the day of the jam, from check-in to the vote. | Read it before you arrive |

## How a lesson is laid out

Every lesson has the same parts, so you always know where to look:

- **Goal**: what you will be able to do at the end.
- **What you'll build**: the thing you will have running.
- **Before you start**: accounts and tools you need.
- **Steps**: numbered, one action each.
- **Concepts**: the ideas behind the steps, in a few lines each.
- **Troubleshooting**: common errors and the fix.

The lessons are short on purpose. They link to Google's official docs for the details, because those docs change faster than we can.
