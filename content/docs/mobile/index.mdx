Google has two main ways to build mobile apps:

- **Flutter**: one codebase in the Dart language for Android, iOS, the web and desktop. Good if you want to reach every platform.
- **Android with Jetpack Compose**: native Android apps in Kotlin. Good if you want to go deep on Android.

This track starts with Flutter, because you can run your first app in Chrome without a phone or an emulator.
