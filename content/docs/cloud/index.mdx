Static sites only send files. As soon as your app needs to run code on a server, for example to keep an API key secret or save data, you need somewhere to run it. The cloud track starts with **Cloud Run**: you give it your code, it runs it, and you pay only while it handles requests.

## Lessons

| Lesson | What you build | Time |
|---|---|---|
| [1. Deploy a web service to Cloud Run](/docs/cloud/1-cloud-run) | A small Node.js service with a public HTTPS address | 40 min |

## What you should know first

- How to run a command in a terminal.
- A little JavaScript. The lesson gives you all the code.
- Google Cloud with billing on. The [$300 free trial](/docs/setup/google-cloud-credits) covers this track.

## Where to go next

- [Cloud Run docs](https://cloud.google.com/run/docs)
- [Google Skills](https://www.skills.google): guided labs. Use your [lab credits](/docs/setup/google-cloud-credits).
- Pair it with the [AI track](/docs/ai): a Cloud Run service is a good place to call Gemini without exposing your key.
