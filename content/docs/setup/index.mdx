Claim these before you start a track. Each guide is a short list of steps.

| Guide | What you get | Card needed? | Time |
|---|---|---|---|
| [Gemini API key](/docs/setup/ai-studio-key) | A free key to call Gemini from your code | No | 5 min |
| [Google AI for students](/docs/setup/google-ai-students) | A free year of a paid Gemini plan | Yes | 10 min, plus verification |
| [Google Cloud credits](/docs/setup/google-cloud-credits) | $300 free trial credit, or lab credits | Trial: yes. Lab credits: no | 10 min |
| [GitHub Student Developer Pack](/docs/setup/github-student-pack) | Copilot, GitHub Pro and partner offers | No | 10 min, plus verification |

## Which ones do I need?

- **Code Jam or the AI track**: the Gemini API key. That is all.
- **Web track**: a Google account. Firebase Hosting is free on the Spark plan.
- **Cloud track**: Google Cloud with billing turned on. The $300 trial covers it.
- **Any track**: the GitHub Student Developer Pack is worth having.

## Before you start

- Use a **personal Google account** (an `@gmail.com` address). Many student offers do not work with school accounts.
- Several offers need you to be **18 or older**. Each guide says so where it applies.
- If a guide asks for a card, read its notes first. Set a reminder to cancel anything you do not want to keep.
