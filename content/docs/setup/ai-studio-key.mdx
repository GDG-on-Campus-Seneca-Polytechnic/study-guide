---
title: Get a Gemini API key
description: Create a free key in Google AI Studio so your code can call Gemini.
---

**You need:** a personal Google account, age 18 or older. **Cost:** free. No card needed. **Time:** 5 minutes.

<Steps>
<Step n={1} guide="ai-studio-key" title="Open AI Studio's API key page" alt="The AI Studio sign-in page at aistudio.google.com/apikey">

Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey) and sign in with your personal Google account.

</Step>
<Step n={2} guide="ai-studio-key" title="Accept the terms" alt="The AI Studio terms of service dialog">

If this is your first time, accept the Terms of Service. AI Studio then creates a default Google Cloud project and an API key for you.

</Step>
<Step n={3} guide="ai-studio-key" title="Create a key if you need another one" alt="The API Keys page with the Create API key button highlighted">

On the **API Keys** page, click **Create API key**. <Check>the screens inside the create-key dialog are not described in the docs.</Check>

</Step>
<Step n={4} guide="ai-studio-key" title="Copy the key" alt="The API Keys page with the copy button next to a key highlighted">

Copy the key. Paste it somewhere private for now, like a password manager. Do not paste it into chat or a shared doc.

</Step>
<Step n={5} guide="ai-studio-key" title="Save it as an environment variable" alt="A terminal with the export GEMINI_API_KEY command">

The Gemini SDKs read the key from `GEMINI_API_KEY`. On macOS or Linux:

```bash
export GEMINI_API_KEY="paste-your-key-here"
```

On Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="paste-your-key-here"
```

</Step>
<Step n={6} guide="ai-studio-key" title="Restrict the key (recommended)" alt="The Add restrictions menu with Restrict to Gemini API only selected">

On the **API Keys** page, use **Add restrictions**, then **Restrict to Gemini API only**. A leaked key can then only call Gemini.

</Step>
<Step n={7} guide="ai-studio-key" title="Check your limits" alt="The AI Studio rate limit page">

Open [aistudio.google.com/rate-limit](https://aistudio.google.com/rate-limit) to see how many requests you can make on the free tier. Limits change often, so check here instead of trusting a number in a blog post.

</Step>
</Steps>

## Keep the key safe

- Treat it like a password. Never commit it to Git, and never put it in front-end or mobile app code.
- If it leaks, create a new key, switch your code to it, then delete the old one.
- On the free tier, Google may use your prompts and outputs to improve its products, and people may review them. Do not send personal or private data.

## Already use Google Cloud?

In AI Studio, open **Dashboard**, then **Projects**, then **Import projects**, and pick your project. Imported projects may need verification before they can use the free tier.

Next: [make your first Gemini call](/docs/ai/1-first-gemini-call).
