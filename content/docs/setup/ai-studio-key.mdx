---
title: Get a Gemini API key
description: Create a free key in Google AI Studio so your code can call Gemini.
---

**You need:** a personal Google account, age 18 or older. **Cost:** free. No card needed. **Time:** 5 minutes.

<Steps>
<Step n={1} guide="ai-studio-key" title="Open AI Studio and find Get API key" alt="Google AI Studio's home screen with the key icon at the bottom left circled">

Go to [aistudio.google.com](https://aistudio.google.com) and sign in with your personal Google account. If AI Studio asks about cookies or terms, read them and choose. Then click the **key icon** at the bottom left (its tooltip says **Get API key**).

</Step>
<Step n={2} guide="ai-studio-key" title="Click Create API key" alt="The API Keys page with the Create API key button circled">

You land on the **API Keys** page. Click **Create API key** at the top right.

</Step>
<Step n={3} guide="ai-studio-key" title="Name the key and pick a project" alt="The Create a new key dialog with the Create key button circled">

Give the key a name you will recognize, like `Code Jam`. Then pick a project from **Choose an imported project**. If you already have a project you want to use, pick it and skip to step 6.

</Step>
<Step n={4} guide="ai-studio-key" title="No project yet? Create one" alt="The project menu open, with Create project circled">

Open the project menu and choose **Create project**.

</Step>
<Step n={5} guide="ai-studio-key" title="Name your project" alt="The Create a new project dialog with the Create project button circled">

Type a name like `Code Jam` and click **Create project**. AI Studio shows **New project created!** and selects it for you.

</Step>
<Step n={6} guide="ai-studio-key" title="Create the key" alt="The Create a new key dialog with the new project selected and Create key circled">

Check that your new project is selected, then click **Create key**.

</Step>
<Step n={7} guide="ai-studio-key" title="Copy the key" alt="The API key details dialog with the key hidden and the Copy key button circled">

The **API key details** window shows your key. Click **Copy key** and paste it somewhere private, like a password manager. Do not paste it into chat, a shared doc, or a public repo. You can always open this window again from the API Keys page.

</Step>
<Step n={8} title="Save it as an environment variable">

The Gemini SDKs read the key from `GEMINI_API_KEY`. On macOS or Linux:

```bash
export GEMINI_API_KEY="paste-your-key-here"
```

On Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="paste-your-key-here"
```

</Step>
<Step n={9} title="Restrict the key (recommended)">

On the **API Keys** page, use **Add restrictions**, then **Restrict to Gemini API only**. A leaked key can then only call Gemini.

</Step>
<Step n={10} title="Check your limits">

Open [aistudio.google.com/rate-limit](https://aistudio.google.com/rate-limit) to see how many requests you can make on the free tier. Limits change often, so check here instead of trusting a number in a blog post.

</Step>
</Steps>

## Keep the key safe

- Treat it like a password. Never commit it to Git, and never put it in front-end or mobile app code.
- If it leaks, create a new key, switch your code to it, then delete the old one.
- On the free tier, Google may use your prompts and outputs to improve its products, and people may review them. Do not send personal or private data.

## Already use Google Cloud?

In AI Studio, open **Dashboard**, then **Projects**, then **Import projects**, and pick your project. Imported projects may need verification before they can use the free tier.
