The web track starts with the fastest win: a page of yours, live on the internet, with a real address you can share.

## Lessons

| Lesson | What you build | Time |
|---|---|---|
| [1. Put a site online with Firebase Hosting](/docs/web/1-firebase-hosting) | A one-page site at `your-project.web.app` | 30 min |

## What you should know first

- Basic HTML: a page with a heading, a paragraph and a link.
- How to open a terminal and run a command.

New to HTML? Work through [MDN's Getting started with the web](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website) first.

## Where to go next

- [Firebase Hosting docs](https://firebase.google.com/docs/hosting): custom domains, redirects and deploying from GitHub.
- [web.dev Learn](https://web.dev/learn): Google's free courses on HTML, CSS, accessibility and performance.
- Want a backend? Go to the [Cloud track](/docs/cloud).
