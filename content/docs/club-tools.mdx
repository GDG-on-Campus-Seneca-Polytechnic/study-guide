Club members built these apps for our events. Each one is open source in the chapter's GitHub organization.

## How they fit together

<Diagram name="club-system" />

On event day, phones scan a QR code on the projector to join a game or open the ballot. The organizer runs the vote from its host page. Both apps run on Cloudflare Workers, with Durable Objects holding each game room or poll. This study guide is a separate static site on GitHub Pages.
