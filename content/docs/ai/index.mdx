This track gets you from "I have an API key" to a small program that uses Gemini. It is also the best preparation for the [Code Jam](/docs/code-jam).

## Lessons

| Lesson | What you build | Time |
|---|---|---|
| [1. Your first Gemini call](/docs/ai/1-first-gemini-call) | A script that sends a prompt and prints the answer | 20 min |
| [2. Give Gemini a role](/docs/ai/2-system-instructions) | A study buddy that answers in a fixed style | 20 min |

## What you need

- A [Gemini API key](/docs/setup/ai-studio-key). Free, no card.
- Node.js or Python. Each lesson shows both.

## No code yet?

Try prompts in [Google AI Studio](https://aistudio.google.com) first. Its **Build mode** can also make a small web app from a description, which is a fast way to prototype a Code Jam idea. See [Build mode](https://aistudio.google.com/docs/aistudio-build-mode).

## Where to go next

- [Gemini API docs](https://aistudio.google.com/docs): images, files, structured output and function calling.
- [Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course): the ideas behind models, if you want to go deeper.
