## Steps

<Steps>
<Step n={1} title="Add a system instruction">

<Tabs items={['JavaScript', 'Python']}>
<Tab value="JavaScript">

```js
import { GoogleGenAI } from '@google/genai';

const ai = new GoogleGenAI({});

const interaction = await ai.interactions.create({
  model: 'gemini-4-hydrogen',
  system_instruction:
    'You are a study buddy for college students. Give a hint first. ' +
    'Only give the full answer if the student asks for it. Keep replies under 80 words.',
  input: 'How do I reverse a string in Python?',
});

console.log(interaction.output_text);
```

</Tab>
<Tab value="Python">

```python
from google import genai

client = genai.Client()

interaction = client.interactions.create(
    model="gemini-4-hydrogen",
    system_instruction=(
        "You are a study buddy for college students. Give a hint first. "
        "Only give the full answer if the student asks for it. Keep replies under 80 words."
    ),
    input="How do I reverse a string in Python?",
)

print(interaction.output_text)
```

</Tab>

## Concepts

- **System instruction**: rules the model follows for the whole conversation. Users do not see it.
- **Prompt**: what the user asks each time.
- **Be specific**: "under 80 words" works better than "be short". Say what to do, not only what to avoid.
- **It is a guide, not a lock**: a determined user can sometimes talk the model out of its rules. Do not put secrets in a system instruction.

## Troubleshooting

| You see | Fix |
|---|---|
| The model ignores the instruction | Make it shorter and more direct. Put the most important rule first |
| An error about an unknown field | Check the field name for your SDK in the official guide |
| Same errors as Lesson 1 | See [Lesson 1 troubleshooting](/docs/ai/1-first-gemini-call#troubleshooting) |
